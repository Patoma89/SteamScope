PREGUNTAS FRECUENTES

Dudas rápidas

¿Necesito una Steam API Key para usarlo?

No para buscar ofertas, usar el Radar Epic/GOG, el Changuito o la Watchlist. Solo la necesitás si querés importar tu biblioteca completa y usar el Valuador de Cuenta o Radar Co-op.

¿Cómo calcula el Dólar Tarjeta vs. Cripto?

Consulta la cotización en vivo mediante DolarAPI (con respaldo automático en CriptoYa) y aplica la carga impositiva vigente o el descuento estimado pagando vía web/cripto.

¿Mis datos o credenciales salen de mi PC?

Nunca. Toda tu configuración, Watchlist, notas privadas y caché de biblioteca se guardan localmente en tu carpeta AppData\Local\SteamScope usando SQLite.

¿Cómo puedo crear mi propia skin?

Podés crear un archivo custom_themes.json dentro de tu carpeta de datos de SteamScope siguiendo la estructura de paletas y la app lo carga automáticamente al iniciar.
